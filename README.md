# Recapp

> 陪你把日常，整理成文章。

Recapp 是一款回顧整理 App，給生活很忙、標準又很高的大學生用。它不幫你代寫，而是一次只問一題，陪你把散在相簿、備忘錄和聊天紀錄裡的碎片，用**自己的話**整理成一篇回顧，再發到 IG、FB、Medium、電子報這些你本來就在用的地方。每一篇都會存進 Library，到了年底串成你的年度故事。

這個 repo 放的是 Recapp 的可互動原型，可以直接拿來做使用者測試。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | **使用者測試版**。打開就是 App 首頁，沒有開場動畫和登入，照片用的是 26 張美國打工度假的測試照片（已內嵌在檔案裡）。 |
| `prototype/index.html` | **完整原型**。包含開場動畫、登入／註冊、左側流程導覽、全螢幕展示和情境測試頁，照片是手繪示意圖。 |

兩個檔案都是單一 HTML，不需要安裝或建置，用瀏覽器打開就能操作。

## 怎麼開

- **電腦**：直接用 Chrome、Edge 或 Safari 打開，App 會顯示在畫面中間的手機框裡。
- **手機**：打開後會自動全螢幕，最接近真實的使用情境。
- **GitHub Pages**：在 repo 的 Settings → Pages 選擇 `main` 分支的根目錄，測試版網址就是 `https://<帳號>.github.io/Recapp/`，完整原型在 `/prototype/`。

字體用的是 justfont 的粉圓（Huninn），從 Google Fonts 載入；離線時會換成系統內建字體，排版不受影響。

## 使用者測試版的流程

1. **首頁**：按「開始新的整理」。
2. **引導四題**，一次只問一題：
   - 想整理什麼事（可以打字或用說的）
   - 想輸出的形式（IG 貼文、IG 限動、FB 貼文、Medium 文章、電子報、個人 Library）
   - 整理哪一段時間（可以切換月份，也有「相簿裡 6/22–8/24 照片最多」的快速選項）
   - 已經有哪些素材
3. **整理清單**：照片、文字、音樂三項，一項一項完成，中途離開會自動儲存。
4. **照片**（照 IG 發文的邏輯）：
   - 點照片就會選取，數字是發布順序。
   - 上方是大預覽，可以放大成全螢幕，左右滑動、直接選取。
   - 選好的照片排成「發布順序」，拖曳就能調整，第一張是封面。
   - 選不出來時按「幫我挑」，會建議 9 張並寫出理由，也會列出可以略過的照片（很像的、不小心拍到的、有個人資料的截圖和單據）。
5. **文字**：五種方法可以混著用，最後整合成一篇。
   - 跟著引導：看照片回想、聊一聊、問題引導
   - 自己來：直接寫、從手機找（備忘錄、聊天紀錄的原文）
   - 「整合成一篇」只用你說過、寫過的內容接成草稿，每段標明來源，可以直接改、調順序或拿掉。
6. **音樂**：替這一頁配一首歌，也可以不配。
7. **產生完整的一頁** → 選擇平台發佈，可以一次選多個平台，各平台會自動調整版面。
8. 發佈完成後可以回首頁，或去 Library 看這一篇。

## 給測試主持人

- **主持人紀錄**：連點三下首頁左上角的 Recapp Logo 打開；用電腦時也可以按 `Shift + L`。
- 紀錄內容包含：總時間、完成發佈的時間、每個畫面的時間點、返回次數、「幫我挑」有沒有開和有沒有套用、放大預覽／拖曳排序／語音輸入的次數，以及最後選的照片順序和用到的文字方法。
- 可以按「複製紀錄」貼到你的筆記，再按「重新開始測試」換下一位受測者。
- **紀錄不會自動存下來**，關掉頁面就沒了，換人之前記得先複製。

### 哪些是模擬的

- **語音輸入**：瀏覽器預覽環境不能開麥克風，按下麥克風會用預先寫好的範例句子模擬即時轉錄，不是受測者真的說的話。
- **幫我挑**：建議與理由是針對這組測試照片寫好的，不是即時分析。
- **發佈**：不會真的發到任何平台。
- **首頁與 Library 的部分插圖**：仍是手繪示意圖，不在測試任務流程裡。

## 設計

- **顏色**：暖白底 `#F6F5F2`、墨色 `#1C1B2E`；珊瑚橘 `#E8481F` 只用在每個畫面唯一的主要行動；太陽黃 `#FFB020` 用在慶祝時刻。
- **字體**：全部用粉圓（Huninn）圓體，「Recapp」字樣用 Outfit。
- **字距與按鈕**：內文 16px／行高 28px、字距 +0.02em；主要按鈕高 56px、字距 +0.1em；珊瑚橘按鈕 19px。
- **中文斷行**：詞不會被拆到兩行，標題只在標點後換行並平均分配長度。
